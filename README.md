# .github

The public profile and brand assets for the Aigentcy GitHub org.

| Path | What it is |
| --- | --- |
| `profile/README.md` | The org profile shown on [github.com/ai-gentcy](https://github.com/ai-gentcy) |
| `profile/assets/` | Wordmarks the profile uses, in light and dark |
| `brand/logo.svg`, `brand/logo-dark.svg` | The `[ai]gentcy` wordmark for light and dark backgrounds |
| `brand/mark.svg` | The `[a]` mark with rounded corners, for app icons and favicons |
| `brand/avatar.svg`, `brand/avatar-*.png` | The `[a]` mark full bleed, for avatars that a platform rounds itself |

All the SVGs use outlined JetBrains Mono Bold, so they render the same without the font installed. Colours: coral `#FF5436`, ink `#14120E`, cream `#FAF8F2`.

The org avatar is `brand/avatar-500.png`. GitHub only accepts it through the org settings page.
